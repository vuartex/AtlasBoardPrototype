# AtlasBoard — Legal & Credits (pre-release ledger)

This is an in-project attribution/review companion, **not** a replacement for the original licenses. The game's Main Menu Credits panel provides condensed recognition; this ledger records detailed rights and release checks.

## Project and technology
- AtlasBoard: project-original game design, integration and custom code.
- Unity Engine, TextMesh Pro, Firebase: third-party software; review each dependency's actual applicable license/distribution terms before release.

## Mandatory release audit — OPEN
1. Confirm every currently **included** source asset has an acquisition record, current license, original author/source, seat eligibility where applicable and permitted integrated game redistribution; candidate-only assets must not be claimed as shipped.
2. Ensure font license notices and any mandatory attribution/notice text ship in the appropriate release distribution.
3. Distinguish CC0 licenses from the Unity Asset Store EULA (including free Store assets). Do not redistribute paid/free Unity Store source files as standalone packages.
4. Audit imported music/SFX especially for author, provenance, license, attribution requirements and noncommercial restrictions; do not infer rights from a filename or from a download appearing on Google.
5. Check Google Play/Steam data privacy policies and storefront legal disclosures independently.
